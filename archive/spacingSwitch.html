Tight Layout

No intentional gaps. Used for flooring, tongue-and-groove, wainscoting, and paneling. Any leftover space becomes ripped edge pieces.

Fixed Gap Field

Uses a constant gap between materials, but no gap at the ends. Common for decking, brick, tile, and siding layouts.

Equal Gaps Everywhere

Creates identical spacing at both ends and throughout the field. Common for balusters, soffit tails, slat walls, and decorative spacing.

Fixed Field Gap + Equal Edges

Keeps field spacing fixed while balancing the edges symmetrically. Useful for certain railing systems and architectural layouts.

Centered Layout / Equal Rips

Prioritizes visual symmetry by centering the layout and splitting remainder evenly across both edges.

Max Fill / Code Layout

Maximizes material quantity while staying under a spacing limit. Common for code-compliant balusters and fencing.
