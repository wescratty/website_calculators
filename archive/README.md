# Archive

Earlier drafts of the spacing calculator, kept for reference but not linked
from anywhere. `js/spacing calculator.html` is the current version.

- `spacing.html`, `spacingOption.html`, `spacingSwitch.html`,
  `cleanerSpacing.html`, `noRadioSpacing.html`, `spacing.js` — early
  iterations exploring different UI approaches (radio buttons, option
  toggles, etc.) for the same board-spacing math.
- `calculator.html` — an earlier full rewrite (five layout modes: tight,
  fixed gap, equal gap, equal gap except ends, max fill) that predates the
  in-progress "desired gap / max gap" rename in the current version.
